# 🌌 VELTRIXA - NASA Space Apps Challenge 2026

**Project:** AI-powered dashboard for exploring NASA's microgravity combustion research.
**Team:** 4 student developers learning and building together.

## 🎯 Project Objective
Our goal is to make complex microgravity combustion data easier to understand. We are building an interactive dashboard that combines data visualization with an AI research assistant to help users explore NASA's datasets.
